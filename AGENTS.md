# Правила работы с проектом

- Не выполнять `git commit` и `git push` без прямого разрешения пользователя.
- После завершения доработки передать изменения пользователю на проверку.
- Менять версию только после подтверждения пользователя, что доработка проверена и работает.
- Использовать Semantic Versioning: `PATCH` — исправления и технические правки, `MINOR` — новая обратно совместимая функциональность, `MAJOR` — несовместимые изменения.
- При изменении структуры проекта обновлять `PROJECT_MAP.md`.
